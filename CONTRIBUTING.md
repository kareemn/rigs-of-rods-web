# Contributing

This is an independent GPL v3 project, not the upstream Rigs of Rods repository. Contributions should keep the standalone app useful without any commercial host.

- Preserve upstream attribution and identify copied/adapted algorithms.
- Include no confidential case data, account credentials, commercial code, or vehicle assets without redistribution rights.
- Run the native, WASM and browser checks listed in README.md.
- State which behavior is ported, approximated or still missing. Add numerical/contact regression cases for physics changes.
- Do not claim that a worker, iframe or API exempts a proprietary integration from GPL.
- Do not describe synthetic fixtures as calibrated real make/model vehicles.

Contributions are licensed under GPL-3.0-only. No copyright assignment or proprietary relicensing permission is requested.
