# Scenario and motion formats, version 1

These are simple project-specific data formats, not the RoR `.truck` or BeamNG JBeam formats. Export a demo scenario to obtain a complete working example.

## Scenario JSON

```json
{
  "version": 1,
  "name": "My impact",
  "environment": {"barrier": false, "barrierX": 0, "gravity": false},
  "nodes": [
    {"position": [0,1,0], "velocity": [1,0,0], "mass": 50, "body": 0},
    {"position": [1,1,0], "velocity": [1,0,0], "mass": 50, "body": 0}
  ],
  "beams": [
    {"a": 0, "b": 1, "stiffness": 230000, "damping": 500,
     "yield": 17000, "strength": 180000, "plastic": 0.55}
  ],
  "triangles": []
}
```

Units: metres, seconds, kilograms, Newtons, stiffness N/m and damping N·s/m. Coordinates are right-handed, Y-up. Synthetic vehicles initially point along local +X. Node indices are zero-based. Triangle winding must point outwards; triangles belonging to different vehicles must not share nodes. Beams start at the distance between their endpoints and must be at least 0.1 m long. A beam's endpoints belong to the same body.

Limits: 2–512 nodes, 4,096 beams, 2,048 triangles, 8 body IDs, positions within ±100 m, initial velocity components within ±40 m/s, node masses 5–10,000 kg. The validator in `src/scenarios.js` defines all remaining parameter bounds. These are guardrails, not a guarantee of stable simulation for every structure.

`vehicles` and `panels` are optional visualization metadata generated by the built-in fixture maker. They are dropped on import. The app derives its generic rendering from node body IDs and triangles.

## Motion JSON

Exported after recording:

```text
{ format: "ror-web-motion", version: 1, scenario: <scenario>,
  frames: [{ time: seconds, positions: [x,y,z,...], damage: [value,...] }, ...] }
```

`positions` follows the scenario node order. `damage` follows the beam order: a nonnegative value is the absolute fractional change in permanent rest length; `-1` marks a broken beam. Frames are sampled at worker-request completion, not every physics tick. No proprietary application adapter or motion-file player is included in this version.
